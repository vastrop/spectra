This folder contains the Pickels library, available for download
from here: http://www.ifa.hawaii.edu/users/pickles/AJP/hilib.html.

Profiles from this folder can be opened in RSpec with the Open command.

THese files are also used by the RSpec Library window.

Files that begin with Ref- are used by the "Lines" tool bar button
on the righthand tool bar.
